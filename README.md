# Система заказов компании «Обувь-Маг»

**Автор:** Орешков С.А., группа И-41

## Что делает программа
– Рассчитывает цену со скидкой 25% для товаров без заказов в прошлом месяце
– Выводит базовую цену и цену со скидкой в консоль
– Демонстрирует работу метода GetDiscountedPrice

## Как запустить
1. Открыть файл `src/lab7/lab7.sln` в SharpDevelop или Visual Studio
2. Нажать F5
3. В консоли появится результат расчёта и фамилия автора
